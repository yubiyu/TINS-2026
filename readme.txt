Mimic Panic
TINS 2026
By Yubi

=== Premise: ===
The mimics are escaping!
Quickly teleport them back into containment with the mimic_suppression_array.
Too slow and they will explode, contaminating the field with radioactive tachyon.
The array will fail if contamination reaches irreversible levels.


=== Controls: ===
Numpad corresponds to the in-game grid.
789 -> Top row
456 -> Middle row
123 -> Bottom row
0   -> Press button in case of Tachyon overflow.


=== Mimics: ===

MOOK:
Typical mimic.
Moves its body with teleportation.
Explodes to spread tachyon contaminant.

CRAB:
Evolution adores a crab.
Projects a field that resists teleportation by the MSA, but only once.

REDIRECTOR:
The MSA was developed by studying this species with an especial affinity for spatial manipulation.
It can redirect the MSA's power to the cell number displayed on its face.

SPLITTER:
Exploits the teleportation paradox to duplicate its own body.

STUNNER:
Placid species that actually prefers conditions in containment. 
Will return on its own time, but retaliates if provoked.

VARIABLE:
Species rumoured to exist by astronauts high on catnip.


Windows Build:
1) Set ALLEGRO_PATH in makefile.win
2) mingw32-make -f makefile.win

Linux Build:
1) make -f makefile.lin
